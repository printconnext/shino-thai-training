1. ภาพรวมของระบบ

ระบบบันทึกข้อมูลพนักงาน เป็นแอปพลิเคชันแบบ Serverless ที่ทำงานได้โดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม เพียงแค่เปิดไฟล์ HTML ด้วย Web Browser ก็สามารถใช้งานได้ทันที

💡 จุดเด่นของระบบ:
  • ไม่ต้องติดตั้งโปรแกรม - เปิดด้วย Browser ได้เลย
  • ไม่ต้องต่ออินเทอร์เน็ต - ใช้งานแบบ Offline ได้
  • บันทึกข้อมูลเป็นไฟล์ CSV - เปิดดูใน Excel ได้
  • มีระบบ Autocomplete - แนะนำข้อมูลที่เคยกรอก

2. การเริ่มต้นใช้งาน

1 เปิดไฟล์ระบบ
ดับเบิลคลิกที่ไฟล์ index.html เพื่อเปิดในเว็บบราวเซอร์ (แนะนำ Google Chrome หรือ Microsoft Edge)
2 หน้าจอหลัก
เมื่อเปิดระบบ จะพบกับหน้าจอหลักที่ประกอบด้วย:
  • 📝 ส่วนกรอกข้อมูลทั่วไป (General Info)
  • 📚 ส่วนประวัติการอบรม (Training History)
  • 📊 ตารางแสดงข้อมูลพนักงาน

3. การกรอกข้อมูลพนักงาน

ข้อมูลที่ต้องกรอก

ช่อง คำอธิบาย
เลขที่บัตร หมายเลขบัตรพนักงาน
หมายเลขบัตรประชาชน เลข 13 หลัก (ไม่ต้องใส่ขีด)
ชื่อ-นามสกุล ชื่อเต็มของพนักงาน (บังคับกรอก)
ตำแหน่ง ตำแหน่งงานปัจจุบัน
สังกัด (ชุด) หน่วยงาน หรือ ทีมที่สังกัด
บริษัท ชื่อบริษัท
สถานะการทำงาน ปกติ / ลาออก / พักงาน / อื่นๆ
วันหมดอายุบัตร วันหมดอายุบัตรประชาชน/พาสปอร์ต
💡 ระบบ Autocomplete:
เมื่อพิมพ์ในช่องต่างๆ ระบบจะแสดงรายการแนะนำจากข้อมูลที่เคยกรอกไว้ก่อนหน้า สามารถคลิกเลือกได้เลย ไม่ต้องพิมพ์ใหม่ทั้งหมด

4. การเพิ่มประวัติการอบรม

1 พิมพ์ชื่อหลักสูตร
ในช่อง "เพิ่มรายการอบรม" พิมพ์ชื่อหลักสูตร หรือเลือกจากรายการที่แนะนำ
2 เลือกวันที่อบรม
คลิกที่ช่องวันที่ แล้วเลือกวันที่อบรม (ไม่บังคับ)
3 กดปุ่ม "+ เพิ่มลงรายการ"
หลักสูตรจะถูกเพิ่มเข้าไปในตาราง "รายการอบรม" ด้านล่าง
4 เพิ่มหลักสูตรเพิ่มเติม
ทำซ้ำขั้นตอน 1-3 สำหรับหลักสูตรอื่นๆ ที่ต้องการเพิ่ม
5 บันทึกข้อมูลพนักงาน
เมื่อกรอกข้อมูลครบแล้ว กดปุ่ม "✅ บันทึกข้อมูลพนักงาน"
⚠️ สำคัญ: หลักสูตรใหม่ที่พิมพ์เข้าไป จะถูกจดจำโดยอัตโนมัติ และจะปรากฏในรายการแนะนำสำหรับพนักงานคนต่อไป

5. การบันทึกข้อมูล (Export CSV)

เนื่องจากระบบเก็บข้อมูลใน Web Browser ชั่วคราว หากปิดหน้าต่างหรือปิดคอมพิวเตอร์ ข้อมูลจะหายไป จึงต้อง Export เป็นไฟล์ CSV เพื่อเก็บข้อมูลถาวร

1 กดปุ่ม "💾 Export as CSV" ที่ด้านบนตาราง
2 ไฟล์ HR_Records.csv จะถูกดาวน์โหลดลงคอมพิวเตอร์
3 เก็บไฟล์นี้ไว้อย่างปลอดภัย สามารถเปิดดูด้วย Microsoft Excel ได้
⚠️ แนะนำ: ควร Export ไฟล์ทุกครั้งหลังจากกรอกข้อมูลเสร็จ เพื่อป้องกันข้อมูลสูญหาย

6. การนำเข้าข้อมูล (Import CSV)

เมื่อต้องการทำงานต่อจากข้อมูลเดิมที่เคย Export ไว้:

1 กดปุ่ม "Choose File" ที่ช่อง "จัดการไฟล์"
2 เลือกไฟล์ CSV ที่เคย Export ไว้
3 ระบบจะถามว่าต้องการ:
  • เพิ่มต่อ (Append) - เพิ่มข้อมูลใหม่ต่อจากข้อมูลเดิม
  • ลงใหม่ (Replace) - ลบข้อมูลเดิมแล้วใส่ข้อมูลใหม่แทน
4 ข้อมูลจะปรากฏในตาราง พร้อมให้แก้ไขหรือเพิ่มเติม

7. การแก้ไขและลบข้อมูล

การลบข้อมูลพนักงาน

1 ในตารางหลัก คลิกปุ่ม "ลบ" ที่แถวของพนักงานที่ต้องการลบ
2 ระบบจะแสดงกล่องยืนยัน กด "OK" เพื่อยืนยันการลบ

การแก้ไขข้อมูล

ระบบปัจจุบันไม่มีฟังก์ชันแก้ไขโดยตรง หากต้องการแก้ไขข้อมูล:

  1. ลบข้อมูลพนักงานคนนั้นออก
  2. กรอกข้อมูลใหม่ที่ถูกต้อง
  3. กดบันทึกข้อมูลพนักงาน

8. คำถามที่พบบ่อย (FAQ)

❓ ข้อมูลหายไปหลังปิดหน้าต่าง?

ตอบ: ระบบเก็บข้อมูลชั่วคราวใน Browser เท่านั้น ต้อง Export เป็น CSV ทุกครั้งหลังกรอกข้อมูลเสร็จ เมื่อเปิดระบบใหม่ ให้ Import ไฟล์ CSV กลับเข้ามา

❓ เปิดไฟล์ CSV ใน Excel แล้วเป็นภาษาต่างดาว?

ตอบ: ให้เปิดด้วยวิธี Import Data ใน Excel แทนการดับเบิลคลิก โดยเลือก Encoding เป็น UTF-8

❓ ต้องมีอินเทอร์เน็ตไหม?

ตอบ: ไม่จำเป็น ระบบทำงานแบบ Offline ได้ ยกเว้นหากต้องการให้ฟอนต์แสดงผลสวยงาม อาจต้องใช้อินเทอร์เน็ตครั้งแรก

❓ ใช้กับโทรศัพท์มือถือได้ไหม?

ตอบ: ได้ แต่แนะนำให้ใช้กับคอมพิวเตอร์เพื่อความสะดวกในการกรอกข้อมูลและ Export/Import ไฟล์
